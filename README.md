# rustavel

> A Laravel-inspired Rust web framework for building scalable web applications
> with elegant syntax, a developer-friendly CLI, and blazing-fast performance.

![Rust](https://img.shields.io/badge/Rust-B94700?style=flat&logo=rust&logoColor=white)
![MIT License](https://img.shields.io/badge/License-MIT-green?style=flat)
![Work in Progress](https://img.shields.io/badge/Status-Work%20in%20Progress-yellow?style=flat)

---

## 🇬🇧 English

| | |
|---|---|
| **Name** | Rustavel |
| **CLI** | `rusty` — `cargo rusty` |
| **License** | MIT |
| **Language** | Rust 🦀 |

### Philosophy
> **Convention over configuration** — you focus on building, Rustavel handles the rest.

### Vision
Bring the **elegance and simplicity of Laravel** to the Rust ecosystem,
without sacrificing performance.

### Target audience
- → Laravel/PHP developers ready to migrate to Rust
- → Rust developers who want a productive, batteries-included framework
- → Teams who want blazing-fast performance without giving up developer experience

### CLI — `cargo rusty`
```bash
cargo rusty make:model
cargo rusty make:controller
cargo rusty migrate
cargo rusty serve
```
